# garisenda

The top-level names: the analysis, its result, sweeps and inputs with sources. Import the package as `gs`:

```python
import garisenda as gs
```

`gs.units` is garisenda's [pint](https://pint.readthedocs.io/) unit registry: give every quantity in it, as `1 * gs.units.percent` or `6.0 * gs.units.m`.
